# Local evidence

Integration scripts generate readback receipts, model usage records and screenshots here. Generated files are excluded from Git because they can contain identifiers from a developer's local applications. Review and redact individual artifacts separately before including them in a submission.

A fresh clone does not include a seeded patient journey or local receipts. Scripts that consume prior evidence require their prerequisite scenario runs. See docs/RUNNING.md and docs/COMEMR-FOLLOWUP.md.
